## Privacy Note

This public repository intentionally excludes internal career databases, source resume drafts, build scripts, screenshots with sensitive data, credentials, API keys, patient data, and private clinic documentation.

Before publishing updates, scan for:

- Patient names or identifiers
- Phone numbers not intended for public release
- Emails other than the public contact email
- Credentials, API keys, tokens, secrets, or passwords
- Private clinic data or operational details
