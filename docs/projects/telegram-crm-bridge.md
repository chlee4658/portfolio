# Telegram CRM Bridge

## Public Summary

Recruiter-facing summary of a staff operations assistant project. It avoids patient data, credentials, and private clinic details.

## Purpose

Telegram CRM Bridge is a staff-facing operational assistant that lets clinic staff use Telegram for controlled customer lookup, booking lookup, and approved template messaging.

## Functional Scope

- Telegram Bot API webhook service
- Customer lookup
- Booking lookup
- Approved template message preview and send flow
- Confirmation gates before external messaging actions
- Audit logging
- Reversible feature flags
- Legacy command compatibility
- Privacy-conscious audit behavior that avoids storing raw staff messages

## Technology

Node.js, TypeScript, Telegram Bot API, HTTP webhook service, feature flags, JSON action schemas, allowlisted actions, automated tests, Mac mini LaunchAgent.

## Career Relevance

Telegram CRM Bridge demonstrates safe operational automation, staff-facing workflow design, controlled AI/action patterns, privacy-aware logging, and live-environment rollout planning.

## Supported Claims

- Provided a controlled staff messaging interface
- Protected operational integrity with approved templates and confirmations
- Preserved legacy command workflows while adding a newer assistant layer
- Added audit and rollout controls for operational safety
